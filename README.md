# v!d by Kold.Gold · Descargas

Aquí se descarga **v!d by Kold.Gold**, la app de videos con agentes de IA. Es exclusiva para usuarios de Kold.Gold: para usarla necesitas una **licencia mensual**.

## Descargar

Ve a **[la última versión](https://github.com/tazkore/vid-descargas/releases/latest)** y elige tu sistema:

| Sistema | Archivo |
| --- | --- |
| Windows 10 u 11 | `vid-koldgold-Setup-<versión>.exe` |
| Mac con Apple Silicon (M1 o más nuevo) | `vid-koldgold-<versión>-mac-arm64.dmg` |
| Mac con Intel | `vid-koldgold-<versión>-mac-x64.dmg` |

`SHA256SUMS.txt` trae las sumas de verificación.

## Instalar

- **Windows:** abre el instalador. Si SmartScreen avisa, pulsa **Más información → Ejecutar de todas formas**. Instalar encima de una versión anterior conserva tus datos.
- **Mac:** abre el `.dmg` y arrastra la app a Aplicaciones. La primera vez, clic derecho sobre la app → **Abrir**. Si macOS no la deja abrir, en la Terminal: `xattr -cr "/Applications/v!d by Kold.Gold.app"`

## Activar tu licencia

Al abrir v!d, escribe tu clave (`VID-XXXXX-XXXXX-XXXXX-XXXXX`) y pulsa **Activar**. También está en **Opciones → Licencia**. Cada licencia sirve hasta en 2 computadoras y se renueva cada mes.

¿No tienes clave o necesitas renovarla? Escribe a **operaciones@kold.gold**.
